# alexdevlabs/tap

Homebrew formulae for [alexdevlabs](https://github.com/alexdevlabs) projects.

```bash
brew install alexdevlabs/tap/aws-autoconnect
```

| Formula | What |
|---|---|
| [`aws-autoconnect`](https://github.com/alexdevlabs/aws-auto-connect) | macOS menu bar app that keeps AWS SSO signed in and AWS Client VPN (SAML) connected |
